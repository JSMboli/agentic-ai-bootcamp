# Agentic AI Bootcamp Student Portal

A modern public-facing static website for sharing the Agentic AI Bootcamp materials on GitHub Pages.

## Files included

- `index.html`
- `styles.css`
- `scripts.js`

## How to publish on GitHub Pages

1. Create a repository for the site, or use your personal GitHub Pages repository.
2. Upload the files in this folder to the root of the repository.
3. Replace the placeholder links in `index.html` with your actual GitHub release or file URLs.
4. In GitHub, go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the appropriate branch (usually `main`) and the root folder.
7. Save and wait for the site to publish.

## Suggested customisations

- Replace placeholder download links in the Downloads section.
- Update the programme summary to match your final structure.
- Add your GitHub repository URL and any additional student contact details.
- Optionally add real graphics or photographs if you wish.
